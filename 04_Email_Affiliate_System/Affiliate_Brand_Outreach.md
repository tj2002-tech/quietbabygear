# 联盟和品牌合作落地

## 第一阶段联盟

优先级：

1. Amazon Associates
2. Impact.com
3. ShareASale
4. 品牌官网 affiliate program

## 品牌筛选标准

- 美国市场可购买
- 母婴产品线清晰
- 有 affiliate 或 creator program
- 产品适合做真实测试
- 愿意提供样品但不要求正面评价

## 品牌 outreach 邮件模板

Subject:

`Independent real-world baby gear testing: QuietBabyGear`

Body:

Hi [Name],

I run QuietBabyGear, a small first-party baby gear testing project focused on real-world parent friction: cleaning time, night-time usability, sound level, leakage, and long-term maintenance.

We are currently building our first nasal aspirator testing database and are looking for brands open to independent product testing.

Our reviews include measured data, original photos, and clear disclosure. We do not guarantee positive coverage, but we do publish practical, parent-focused findings.

If you have an affiliate or creator program, I would be happy to learn more.

Best,
[Name]

## 合作底线

- 不接受必须好评的合作
- 不接受医疗功效话术
- 不删除真实缺点
- 样品必须披露
