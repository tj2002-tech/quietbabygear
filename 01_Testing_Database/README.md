# QuietBabyGear Testing Database

这里存放 QuietBabyGear 的核心资产：第一方测试协议、原始数据、Lab Notes 和产品观察记录。

## 数据纪律

- 原始数据不美化
- 测试失败也记录
- 不删除负面体验
- 每个结论必须能追溯到某条数据或素材
- 每张图片必须能对应产品编号和测试日期

## 核心文件

- `Testing_Protocol_v1.md`：标准测试协议
- `Product_Test_Log.csv`：产品测试总表
- `Lab_Notes_Template.md`：单条实验笔记模板
- `Lab_Notes_Index.csv`：Lab Notes 索引
