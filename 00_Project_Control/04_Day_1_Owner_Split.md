# Day 1 分工：启动 QuietBabyGear

今天的目标不是做完网站，而是把项目从“想法”推进到“可执行状态”。

## 今天完成标准

- 品牌域名方向确定
- 建站方案确定
- 项目邮箱准备
- 首批 5 个产品采购决策完成
- 测试工具清单确认
- 账号注册顺序确认
- 明天可以直接开始网站搭建

## 你需要准备

### 1. 域名偏好

准备 3-5 个可接受域名方向。

优先级：

1. `quietbabygear.com`
2. `quietbabygear.co`
3. `quietbabylab.com`
4. `quietnurserygear.com`
5. `sleepyparentgear.com`

判断标准：

- 简短
- 英文用户容易读
- 不像医疗站
- 不限制未来扩品类
- 能承载 testing database 定位

### 2. 建站预算选择

选择一个：

| 方案 | 适合情况 | 月成本 |
|---|---|---:|
| Hostinger WordPress | 最省事，适合快速启动 | 约 $3-$10 |
| Cloudways + WordPress | 更稳、更适合长期运营 | 约 $11-$15 |
| 先本地规划，晚点上线 | 暂时不想付费 | $0 |

建议：

如果你已经决定认真做，选 Cloudways 或 Hostinger 都可以。第一阶段不要折腾复杂技术。

### 3. 项目邮箱

准备一个专用邮箱。

推荐格式：

- `hello@quietbabygear.com`
- `research@quietbabygear.com`
- 如果域名邮箱暂时没开，用 Gmail 过渡：`quietbabygear@gmail.com`

### 4. 首批产品购买决策

今天至少确认先买哪 3 个。

建议第一批先买：

1. Frida NoseFrida
2. Grownsy Electric
3. Nosiboo Pro

原因：

- 一个手动经典
- 一个性价比电动
- 一个高端电动
- 三者差异明显，最容易跑通测试体系

### 5. 测试工具

先确认你是否已经有：

- 手机三脚架
- 小台灯或暖光灯
- 秒表，手机即可
- 分贝仪 App，手机即可
- 白色桌面或固定拍摄背景
- 量杯或滴管
- 纸巾、清洗盆、晾干架

今天不需要全部买齐，但要知道缺什么。

### 6. 账号注册准备

先不用全部发内容，但要准备注册：

- Pinterest
- Reddit
- Medium
- Substack
- Quora

用户名优先：

- QuietBabyGear
- QuietBabyLab
- QuietNurseryGear
