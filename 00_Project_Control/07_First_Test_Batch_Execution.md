# 首批测评执行方案：先 3 个，后 5 个

## 结论

第一阶段不要直接买 5 个，也不要只写 3 个就宣称“best overall”。

正确打法：

1. 先买 3 个产品，做 Pilot Test。
2. 用 3 个产品跑通 MCT、SSS、OOH、LFI、MRS 的测试流程。
3. 发布第一篇时写成 `3AM Cleaning Pilot Test` 或 `First Round Test`。
4. 第 2 轮再补 2 个产品，升级成 5-product comparison。

## 为什么先测 3 个

- 成本更低
- 测试流程更容易校准
- 拍摄和素材管理压力更小
- 可以先发现测试表是否有问题
- 不会因为一次买太多导致执行拖延

## 第一批推荐 3 个

| 优先级 | 产品 | 定位 | 为什么选 |
|---|---|---|---|
| P0 | Frida Baby NoseFrida | 手动经典基准 | 市场认知高，适合做 manual benchmark |
| P0 | Grownsy Electric Nasal Aspirator | Amazon 热门电动款 | 价格中等、评论多，用户讨论多 |
| P0 | Braun Electric Nasal Aspirator | 传统品牌电动款 | 品牌信任感强，适合和 Grownsy 对比 |

## 第二批补充 2 个

| 优先级 | 产品 | 定位 | 备注 |
|---|---|---|---|
| P1 | Nosiboo Pro 或 Dr. Noze Best NozeBot | 高端电动款 | 二选一，作为 premium reference |
| P1 | Momcozy BreezyClear 或 Frida Electric NoseFrida Pro | 新锐/升级电动款 | 适合做功能复杂度和清洗摩擦测试 |

## 为什么第一批不优先买 Nosiboo

Nosiboo 或 NozeBot 很适合做高端对照，但价格高。第一轮最重要的是验证测试协议，而不是一次性覆盖高端市场。

如果预算宽松，可以直接加一个高端款，把第一批变成 4 个：

- Frida NoseFrida
- Grownsy Electric
- Braun Electric
- Nosiboo Pro 或 NozeBot

## 第一篇文章标题建议

不要用：

`Best Baby Nasal Aspirator 2026`

建议用：

`We Timed 3 Baby Nasal Aspirators at 3AM: Cleaning Friction Pilot Test`

或者：

`Easiest Baby Nasal Aspirator to Clean at 3AM: First-Round Testing Notes`

## 第一篇文章定位

这不是最终排行榜，而是第一轮真实测试。

文章里明确写：

> This is our first-round cleaning friction test. We are starting with three widely available aspirators to calibrate our testing protocol before expanding the database.

## 具体执行步骤

### Step 1：下单

先买：

- Frida Baby NoseFrida
- Grownsy Electric Nasal Aspirator
- Braun Electric Nasal Aspirator

### Step 2：到货后先不急着写文章

每个产品先拍：

- 包装正面
- 包装背面
- 配件平铺
- 说明书清洗部分
- 产品手持比例
- 初次拆洗过程

### Step 3：每个产品做 3 次 MCT

每个产品跑 3 次清洗计时：

- 第 1 次：完全新手状态
- 第 2 次：熟悉后
- 第 3 次：低光模拟 3AM

取：

- 最快时间
- 最慢时间
- 平均时间
- 最大卡点

### Step 4：做 SSS 噪音测试

每个电动产品测：

- 背景噪音
- 低档分贝
- 高档分贝

Frida 手动款记录：

- 无电机噪音
- 但有使用心理摩擦和清洗摩擦

### Step 5：做 OOH 单手操作测试

每个产品记录：

- 单手拿起
- 单手开关
- 单手调档
- 单手拆洗
- 是否容易滑落

### Step 6：写 Lab Notes

不要等文章，先写至少 3 条 Lab Notes：

- Unboxing friction notes
- First MCT cleaning run
- Low-light one-hand handling notes

### Step 7：发布第一篇 pilot article

文章结构：

1. First-round conclusion
2. Data table
3. Why we started with three products
4. MCT testing method
5. Product-by-product notes
6. What surprised us
7. What we need to retest
8. FAQ
9. Affiliate disclosure

## 第一轮不要做的事

- 不要宣称最终最佳
- 不要给医疗建议
- 不要把吸力当唯一指标
- 不要只引用 Amazon 评论
- 不要先写结论再找数据
