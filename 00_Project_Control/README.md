# QuietBabyGear 落地工作台

QuietBabyGear 的执行目标不是日更博客，而是持续生产可验证的第一方测试数据、真实素材和可被 AI 搜索引用的消费研究页面。

## 当前阶段

Phase 1：基础搭建期，0-30 天。

## 本阶段唯一目标

在 30 天内完成：

- 网站基础结构上线
- 5 个鼻吸器产品到位
- 第一版 QuietBabyGear Testing Protocol 完成
- 至少 2 篇深度测试内容发布
- 至少 8 条 Lab Notes 原始记录
- Pinterest 每天 2 条，Reddit 每天 5 条无链接互动
- Email lead magnet 初版上线

## 每周工作节奏

| 周期 | 核心动作 | 输出物 |
|---|---|---|
| 周一 | 选题和测试计划 | 本周测试排期、拍摄清单 |
| 周二-周三 | 产品测试和素材采集 | 原始数据、照片、短视频、Lab Notes |
| 周四 | 内容初稿 | 文章草稿、数据表、FAQ |
| 周五 | 发布和分发 | 网站文章、Pinterest、Medium/Substack 摘要 |
| 周六 | 社区互动 | Reddit/Quora 低链接参与 |
| 周日 | 复盘 | 指标记录、下周调整 |

## 每天最低动作

- 记录 1 条 Lab Note
- 拍摄或整理 3 个真实素材
- Pinterest 发布 2 条
- Reddit 正常回复 5 条，不发链接
- 更新一次项目指标表
