# 素材库规范

QuietBabyGear 的素材是核心资产。每个测试素材都必须能追溯到产品、日期和测试场景。

## 文件夹命名

`产品编号_品牌_型号`

示例：

`QBG-ASP-001_Nosiboo_Pro`

## 文件命名

`YYYY-MM-DD_产品编号_测试类型_序号`

示例：

`2026-05-25_QBG-ASP-001_MCT_stopwatch_01.jpg`

## 素材类型

- packaging
- unboxing
- parts_layout
- mct_stopwatch
- cleaning_process
- water_residue
- sound_meter
- one_hand_operation
- leakage
- mold_check
- battery
- night_setup

## 每个产品最低素材量

- 包装 3 张
- 配件 5 张
- 清洗流程 10 张
- 秒表 3 张
- 分贝 3 张
- 单手操作 5 张或 1 个 GIF
- 泄漏测试 3 张
- 发霉观察每个时间点 3 张
