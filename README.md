# QuietBabyGear

QuietBabyGear 是一个面向 2026 AI 搜索时代的母婴微型消费研究站。

核心定位：

`We test baby gear under real-world sleep-deprived parenting conditions.`

这个项目的目标不是批量生产 SEO 文章，而是建立一个可被 AI 搜索引用的第一方消费测试数据库。

## 现在怎么开始

1. 打开 `00_Project_Control/02_First_7_Days_Checklist.md`
2. 按 Day 1 到 Day 7 执行
3. 每天更新 `00_Project_Control/Daily_Operating_Board.csv`
4. 产品到货后填写 `01_Testing_Database/Product_Test_Log.csv`
5. 每次测试都写一条 `01_Testing_Database/Lab_Notes_Template.md`
6. 每周用 `06_Metrics/Weekly_Review_Template.md` 复盘

## 项目结构

- `00_Project_Control/`：总控、路线图、每日看板
- `01_Testing_Database/`：测试协议、产品数据、Lab Notes
- `02_Content_System/`：文章模板、选题、编辑日历
- `03_Distribution_System/`：Pinterest、Reddit、GEO 分发
- `04_Email_Affiliate_System/`：Email、联盟、品牌合作
- `05_Asset_Library/`：素材命名和拍摄清单
- `06_Metrics/`：KPI 和周复盘

## 第一阶段不要做的事

- 不扩品类
- 不写泛泛 best list
- 不用 AI 批量洗稿
- 不发 Reddit 外链
- 不做医疗建议
- 不把 Amazon 佣金当唯一商业模式
